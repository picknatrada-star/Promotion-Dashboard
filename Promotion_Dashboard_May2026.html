SCQA – สถานการณ์และกลยุทธ์

S – Situation: บริษัทมียอดขายโปรโมชั่นสะสม ณ วันที่ 25 พ.ค. = ฿10,200,890 จากเป้าทั้งเดือน ฿14,609,088 คิดเป็น 69.8% GP โปร = 28.6%

C – Complication: ยังเหลือ 6 วัน หากยังคงอัตราเฉลี่ยปัจจุบัน (฿408,036/วัน) คาดทำได้ 86.6% (ขาดเป้า ~฿4.4M) ต้องเร่งรัดโดยเฉพาะ Type H และ Z ที่ยังต่ำกว่าเป้ามาก

Q – Question: จะทำอย่างไรให้บรรลุเป้าโปรโมชั่นทั้งเดือน และรักษา GP ≥ 25%?

A – Answer: เร่ง 5 รายการสินค้าที่ต้อง Action ทันที + เน้น Type ที่ attain% ต่ำ + สื่อสาร push ใน 32 สาขาวิกฤต

🚨 5 รายการสินค้าที่ต้อง Action ทันที

1. ครัวซีกัล – กระทะ/หม้อ (Type D)

ยอดจริง: ฿0 | เป้า: ฿522,000 | attain: 0%
  • จัดแสดงสินค้า end-cap ให้โดดเด่น
  • ฝึกพนักงาน demo สาธิตการใช้งาน
  • Bundle กับสินค้าครัวอื่น เพิ่ม perceived value

2. น้ำยาปรับผ้านุ่ม – รายการ H ราคาสมาชิก

ยอดจริง: ฿0 | เป้า: ฿51,000 | attain: 0%
  • ตรวจสอบ stock และ display ณ สาขา
  • Push LINE OA สมาชิกรับทราบราคาพิเศษ
  • Tie-in กับ wash promotion ในสัปดาห์สุดท้าย

3. ปากกาคาสิโน – Type D ลดราคา

ยอดจริง: ฿0 | เป้า: ฿60,000 | attain: 0%
  • วางหน้าแคชเชียร์ทุกสาขา (impulse buy)
  • จัด multi-pack 3 แท่ง = ฿XX ยิ่งคุ้ม
  • Target โรงเรียน/ออฟฟิศใกล้สาขา

4. ปั๊มลมไฟฟ้า – Type Z แถม GWP

ยอดจริง: ฿0 | เป้า: ฿30,000 | attain: 0%
  • สื่อสาร "ซื้อวันนี้รับของแถมฟรี" ทาง Social
  • เพิ่ม in-store shelf talker ให้ชัดเจน
  • แจ้ง RM ให้กำกับสาขาในเขตที่มียอด 0
